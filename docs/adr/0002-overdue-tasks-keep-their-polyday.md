# Keep overdue tasks assigned to their original polyday

An overdue task remains in its explicitly assigned or deadline-derived polyday and also appears in the current polyday. Rolling it forward merely because time passes would erase the plan, while copying would create independent tasks. Completion is recorded in that polyday even when it happens earlier or later; an untimed task can be explicitly moved, while a deadline task can only be rescheduled by editing its exact date and time, as defined in [ADR 0009](0009-derive-deadline-task-polydays.md).
