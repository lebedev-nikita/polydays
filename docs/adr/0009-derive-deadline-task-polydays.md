# Derive deadline-task placement from its explicit date and time

An untimed task can be assigned to a selected polyday, while a task with an exact deadline derives its polyday from that date and time, using the preceding polyday for sleep-gap deadlines. Deadline tasks cannot be independently moved to a polyday; the user edits the explicit deadline to change placement. This avoids contradictory scheduling inputs and implicit date choices for intervals crossing midnight, accepting different scheduling controls for timed and untimed tasks.
