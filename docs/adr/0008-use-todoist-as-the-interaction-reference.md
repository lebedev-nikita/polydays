# Use Todoist as the interaction reference

The user already works in Todoist and wants Polydays to feel familiar, so use Todoist's visual and interaction conventions as the default for task lists, quick entry, editing, priorities, navigation and widgets. This favours continuity with the user's existing workflow over inventing a separate interaction model; explicit Polydays requirements govern polyday scheduling, history and recurrence where they differ. The reference does not expand the agreed first-version scope to every Todoist feature.
