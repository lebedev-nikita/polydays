# Polydays 0.4.0

Android and macOS (Apple Silicon) are built from the same source commit.

- Search task titles and descriptions, including an optional completed-task view and recurring occurrences for the next 30 days. Open results in the appropriate task list.
- Undo task completion, reopening and deletion while preserving unrelated edits.
- Add tasks inline on desktop and use contextual row actions for editing, scheduling, priority and deletion. Mobile capture retains the keyboard-aware composer; open drafts survive window resizing.
- Collapse the desktop sidebar and use keyboard shortcuts for search, task completion, priorities and shortcut help.
- Refine task-list density, buttons and the shared-client palette while retaining mobile task details, immediate property saves, grouped timelines and Android widget improvements from 0.3.15.
- Keep future release candidates as draft prereleases after verifying both platform artifacts.

## Install

- **Android:** install `Polydays-0.4.0-android-arm64.apk`. It uses the permanent release certificate and Android version code 27. Existing application data is preserved.
- **macOS:** open `Polydays-0.4.0-macos-arm64.dmg` and copy Polydays to Applications. Requires macOS 12 or newer on Apple Silicon. The bundle is ad-hoc signed and is not notarized.

The default server is `https://polydays.home.arpa`. A saved server address takes precedence. Access requires the configured private network and its CA certificate installed on the device. Downloaded tasks remain available offline.

`SHA256SUMS` contains the APK and DMG checksums.
