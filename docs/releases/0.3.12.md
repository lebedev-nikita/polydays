# Polydays 0.3.12

Android and macOS (Apple Silicon) are built from the same source commit.

- Open task details on phones in a Todoist-style bottom sheet with a destination header, completion beside the title, full-width scheduling and priority rows, and an expandable description. Opening details leaves the keyboard closed until a text field is selected.
- Keep desktop editing in place, with the completion circle inside the editor border.
- Move secondary mobile actions into the overflow menu; preserve immediate property saves, text drafts, rescheduling and close-without-changes behaviour.
- Keep mobile editing and its save action above the keyboard.

## Install

- **Android:** install `Polydays-0.3.12-android-arm64.apk`. It uses the permanent release certificate and Android version code 23.
- **macOS:** open `Polydays-0.3.12-macos-arm64.dmg` and copy Polydays to Applications. Requires macOS 12 or newer on Apple Silicon. The bundle is ad-hoc signed and is not notarized.

The default server is `https://polydays.home.arpa`. A saved server address takes precedence. Access requires the configured private network. Downloaded tasks remain available offline.

`SHA256SUMS` contains the APK and DMG checksums.
