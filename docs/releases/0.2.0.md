# Polydays 0.2.0

Android and macOS (Apple Silicon) are built from the same source commit.

- Added an OAuth-protected MCP server for tasks, recurring series, polydays, schedules and timezone settings.
- Added connection approval and revocation pages, separate read/write permissions, safe command retries and revision checks.
- MCP changes use the same synchronization journal as the applications.
- Added a stable Tailscale Service address for the Raspberry Pi deployment: `https://polydays.gibbon-parrotfish.ts.net`.

## Install

- **Android:** install `Polydays-0.2.0-android-arm64.apk`. It uses the permanent release certificate and Android version code 10.
- **macOS:** open `Polydays-0.2.0-macos-arm64.dmg` and copy Polydays to Applications. Requires macOS 12 or newer on Apple Silicon. The bundle is ad-hoc signed and is not notarized.

The default server is `https://polydays.gibbon-parrotfish.ts.net`. A saved server address takes precedence; change it on the sign-in screen after signing out. Access to the configured private servers requires Tailscale; downloaded tasks remain available offline.

See [MCP connection instructions](../mcp.md). Cloud-hosted MCP clients need a separate network tunnel or public entry point to reach a private tailnet service.

`SHA256SUMS` contains the APK and DMG checksums.
