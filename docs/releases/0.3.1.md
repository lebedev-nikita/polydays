# Polydays 0.3.1

Android and macOS (Apple Silicon) are built from the same source commit.

- Fixed task panel borders to follow the panel's rounded corners in quick entry and task details.
- Made P1–P3 flags filled and consistently red, orange and blue in priority menus and controls; P4 remains neutral.
- Added a subtle matching fill to unfinished P1–P3 completion circles in task lists.

## Install

- **Android:** install `Polydays-0.3.1-android-arm64.apk`. It uses the permanent release certificate and Android version code 12.
- **macOS:** open `Polydays-0.3.1-macos-arm64.dmg` and copy Polydays to Applications. Requires macOS 12 or newer on Apple Silicon. The bundle is ad-hoc signed and is not notarized.

The default server is `https://polydays.gibbon-parrotfish.ts.net`. A saved server address takes precedence. The configured service is private; each user needs Tailscale access. Downloaded tasks remain available offline.

`SHA256SUMS` contains the APK and DMG checksums.
