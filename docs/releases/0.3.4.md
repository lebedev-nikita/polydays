# Polydays 0.3.4

Android and macOS (Apple Silicon) are built from the same source commit.

- Redesigned the Android widget to follow the Todoist reference: a compact header, circular add action, refresh control, full-width task rows, priority-colored completion circles and quiet polyday/update information.
- Used Lucide icons in the native widget. The add action opens quick entry for the current polyday; task titles open their inline editor, while completion remains available offline.
- Fixed a widget crash when the launcher requests an outdated row after a task is completed, with a native regression test.
- Included the task editing and scheduling improvements already merged since 0.3.3: edit tasks directly in their lists and choose the date and polyday together in one scheduling menu.

## Install

- **Android:** install `Polydays-0.3.4-android-arm64.apk`. It uses the permanent release certificate and Android version code 15.
- **macOS:** open `Polydays-0.3.4-macos-arm64.dmg` and copy Polydays to Applications. Requires macOS 12 or newer on Apple Silicon. The bundle is ad-hoc signed and is not notarized.

The default server is `https://polydays.gibbon-parrotfish.ts.net`. A saved server address takes precedence. The configured service is private; each user needs Tailscale access. Downloaded tasks remain available offline.

`SHA256SUMS` contains the APK and DMG checksums.
