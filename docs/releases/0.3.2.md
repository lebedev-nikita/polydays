# Polydays 0.3.2

Android and macOS (Apple Silicon) are built from the same source commit.

- Type `!!1`, `!!2`, `!!3` or `!!4` as a separate word in a task title to select P1–P4 immediately. P4 clears the priority.
- The command is removed from the title, the priority control updates, and typing can continue. Shortcuts work when creating or editing tasks and recurring series, including pasted text.

## Install

- **Android:** install `Polydays-0.3.2-android-arm64.apk`. It uses the permanent release certificate and Android version code 13.
- **macOS:** open `Polydays-0.3.2-macos-arm64.dmg` and copy Polydays to Applications. Requires macOS 12 or newer on Apple Silicon. The bundle is ad-hoc signed and is not notarized.

The default server is `https://polydays.gibbon-parrotfish.ts.net`. A saved server address takes precedence. The configured service is private and requires Tailscale access. Downloaded tasks remain available offline.

`SHA256SUMS` contains the APK and DMG checksums.
