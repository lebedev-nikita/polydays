# Polydays 0.4.3

Android and macOS (Apple Silicon) are built from the same source commit.

- Apply compact polyday headings and minimal interface copy across Android, macOS and web.
- Remove task counters and empty polyday sections from plans and history; keep date grouping and scheduling into empty polydays.
- Show separators only between tasks, with no bottom divider after the last task. Place contextual add actions beside timeline headings.
- Simplify sign-in, settings, search, empty states and task forms while retaining errors, confirmations and accessible names.
- Preserve open editors when rescheduling removes the last task from a polyday. Keep additional dates reachable when a list is too short to scroll.

## Install

- **Android:** install `Polydays-0.4.3-android-arm64.apk`. It uses the permanent release certificate and Android version code 30. Existing application data is preserved.
- **macOS:** open `Polydays-0.4.3-macos-arm64.dmg` and copy Polydays to Applications. Requires macOS 12 or newer on Apple Silicon. The bundle is ad-hoc signed and is not notarized.

The default server is `https://polydays.home.arpa`. A saved server address takes precedence. Access requires the configured private network and its CA certificate installed on the device. Downloaded tasks remain available offline.

`SHA256SUMS` contains the APK and DMG checksums.
