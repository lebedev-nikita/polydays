# Polydays 0.1.6

Android and macOS (Apple Silicon) are built from the same source commit.

- Made task entry more compact with smaller property controls and clearer title hierarchy.
- Removed the title focus frame and divider. Empty titles no longer show an error when moving to other fields or properties; adding a task stays inactive until a title is entered.
- Kept priority and recurrence controls compact while preserving accessible names and touch targets.

## Install

- **Android:** install `Polydays-0.1.6-android-arm64.apk`. It uses the permanent release certificate and Android version code 8.
- **macOS:** open `Polydays-0.1.6-macos-arm64.dmg` and copy Polydays to Applications. Requires macOS 12 or newer on Apple Silicon. The bundle is ad-hoc signed and is not notarized.

The default server is `https://macbook.gibbon-parrotfish.ts.net`. You can select another server on the sign-in screen. Access to the configured private servers requires Tailscale; previously downloaded tasks remain available offline.

`SHA256SUMS` contains the APK and DMG checksums.
