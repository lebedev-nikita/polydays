# Polydays 0.1.2

Android and macOS (Apple Silicon) are built from the same source commit.

- Browser navigation no longer flashes a blank screen when opening a page for the first time. Route code loads with the application instead of interrupting the first transition.
- Schedule settings display the calculated duration of each polyday beneath its time fields.
- Added browser regression coverage for first visits on wide and narrow screens, including Back and Forward navigation.

## Install

- **Android:** install `Polydays-0.1.2-android-arm64.apk`. It uses the permanent release certificate and Android version code 4.
- **macOS:** open `Polydays-0.1.2-macos-arm64.dmg` and copy Polydays to Applications, or use the equivalent `.app.zip`. Requires macOS 12 or newer on Apple Silicon. The bundle remains ad-hoc signed and is not notarized.

The default server is `https://macbook.gibbon-parrotfish.ts.net`. You can select another server on the sign-in screen. Access to the configured private servers requires Tailscale; previously downloaded tasks remain available offline.

`SHA256SUMS` contains asset checksums; `release.json` identifies the shared source commit and default server.
