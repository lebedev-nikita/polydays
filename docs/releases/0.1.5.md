# Polydays 0.1.5

Android and macOS (Apple Silicon) are built from the same source commit.

- Fixed the Android keyboard covering the task composer. The title, description and add action now stay above the keyboard, including when it is reopened.
- Verified task entry with a multiline title and enlarged system text. Added a regression check using the real Android keyboard.

## Install

- **Android:** install `Polydays-0.1.5-android-arm64.apk`. It uses the permanent release certificate and Android version code 7.
- **macOS:** open `Polydays-0.1.5-macos-arm64.dmg` and copy Polydays to Applications. Requires macOS 12 or newer on Apple Silicon. The bundle is ad-hoc signed and is not notarized.

The default server is `https://macbook.gibbon-parrotfish.ts.net`. You can select another server on the sign-in screen. Access to the configured private servers requires Tailscale; previously downloaded tasks remain available offline.

`SHA256SUMS` contains the APK and DMG checksums.
