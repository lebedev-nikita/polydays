# Polydays 0.3.15

Android and macOS (Apple Silicon) are built from the same source commit.

- Group upcoming polydays and history by their start date, with one shared task summary and compact names and boundaries beneath it. Overnight intervals remain under their start date.
- Load more future or past dates as the timeline scrolls, without explanatory copy or week navigation. Keep the loaded dates and scroll position when returning from a polyday.
- Switch Android widgets between the current polyday and all polydays of its start date through the chevron beside the title. Choices open over the list; the closed menu reserves no space. Each widget remembers its own selection.
- Preserve separate overdue tasks from earlier dates, priorities and offline completion.

## Install

- **Android:** install `Polydays-0.3.15-android-arm64.apk`. It uses the permanent release certificate and Android version code 26. Existing application data is preserved.
- **macOS:** open `Polydays-0.3.15-macos-arm64.dmg` and copy Polydays to Applications. Requires macOS 12 or newer on Apple Silicon. The bundle is ad-hoc signed and is not notarized.

The default server is `https://polydays.home.arpa`. A saved server address takes precedence. Access requires the configured private network and its CA certificate installed on the device. Downloaded tasks remain available offline.

`SHA256SUMS` contains the APK and DMG checksums.
