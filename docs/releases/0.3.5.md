# Polydays 0.3.5

Android and macOS (Apple Silicon) are built from the same source commit.

- Fixed polyday names appearing to revert after saving and reopening settings. The editor now opens the next saved schedule with its effective date, including changes scheduled beyond tomorrow.
- Added the effective date to the save confirmation. Names and boundaries apply from the selected date; the default remains tomorrow.
- Covered offline reloads, repeated renaming and activation on the selected date with browser regression tests.

## Install

- **Android:** install `Polydays-0.3.5-android-arm64.apk`. It uses the permanent release certificate and Android version code 16.
- **macOS:** open `Polydays-0.3.5-macos-arm64.dmg` and copy Polydays to Applications. Requires macOS 12 or newer on Apple Silicon. The bundle is ad-hoc signed and is not notarized.

The default server is `https://polydays.gibbon-parrotfish.ts.net`. A saved server address takes precedence. The configured service is private; each user needs Tailscale access. Downloaded tasks remain available offline.

`SHA256SUMS` contains the APK and DMG checksums.
