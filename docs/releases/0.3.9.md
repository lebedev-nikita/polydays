# Polydays 0.3.9

Android and macOS (Apple Silicon) are built from the same source commit.

- Save task scheduling, priority and series properties immediately after choosing them. Only title and description need the editor's Save action.
- Preserve saved properties when discarding a text draft. Keep the inline editor open after rescheduling, including when moving the last task out of a list.
- Preserve the previous property value when a save fails and allow retrying the choice.

## Install

- **Android:** install `Polydays-0.3.9-android-arm64.apk`. It uses the permanent release certificate and Android version code 20.
- **macOS:** open `Polydays-0.3.9-macos-arm64.dmg` and copy Polydays to Applications. Requires macOS 12 or newer on Apple Silicon. The bundle is ad-hoc signed and is not notarized.

The default server is `https://polydays.gibbon-parrotfish.ts.net`. A saved server address takes precedence. The configured service is private; each user needs Tailscale access. Downloaded tasks remain available offline.

`SHA256SUMS` contains the APK and DMG checksums.
