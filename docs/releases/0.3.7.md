# Polydays 0.3.7

Android and macOS (Apple Silicon) are built from the same source commit.

- Close task capture after successfully saving a task or recurring series, including offline saves.
- Allow dismissal by pressing the background outside the panel, preserving confirmation before discarding an unsaved draft.
- Keep task capture open when validation or saving fails.

## Install

- **Android:** install `Polydays-0.3.7-android-arm64.apk`. It uses the permanent release certificate and Android version code 18.
- **macOS:** open `Polydays-0.3.7-macos-arm64.dmg` and copy Polydays to Applications. Requires macOS 12 or newer on Apple Silicon. The bundle is ad-hoc signed and is not notarized.

The default server is `https://polydays.gibbon-parrotfish.ts.net`. A saved server address takes precedence. The configured service is private; each user needs Tailscale access. Downloaded tasks remain available offline.

`SHA256SUMS` contains the APK and DMG checksums.
