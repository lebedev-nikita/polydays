# Polydays 0.3.0

Android and macOS (Apple Silicon) are built from the same source commit.

- One server now supports multiple verified Google accounts, each with independent tasks, schedule, history and MCP connections.
- Each person can authorize multiple MCP clients. Revoking one grant leaves other users and clients connected.
- Server administrators can admit all verified accounts or configure an email allowlist. Existing `OWNER_EMAIL` settings remain a fallback until explicitly overridden.
- Application and widget sync requests include their local account identity, preventing a changed browser session from sending queued changes to another account.

## Install

- **Android:** install `Polydays-0.3.0-android-arm64.apk`. It uses the permanent release certificate and Android version code 11.
- **macOS:** open `Polydays-0.3.0-macos-arm64.dmg` and copy Polydays to Applications. Requires macOS 12 or newer on Apple Silicon. The bundle is ad-hoc signed and is not notarized.

The default server is `https://polydays.gibbon-parrotfish.ts.net`. A saved server address takes precedence. The configured service is private; each user needs Tailscale access. Downloaded tasks remain available offline.

See [account admission](../deployment.md#account-access) and [MCP setup](../mcp.md). `SHA256SUMS` contains the APK and DMG checksums.
