# Polydays 0.1.4

Android and macOS (Apple Silicon) are built from the same source commit.

- Opening inbox, current and selected polydays, upcoming polydays and history now displays the destination immediately, with a loading indicator while its list is prepared.
- The same behavior applies to week changes, back navigation and opening task details. Pending list preparation is cancelled when leaving a screen.
- This change is shared by Android, macOS and the web client; navigation does not wait for server synchronisation.

## Install

- **Android:** install `Polydays-0.1.4-android-arm64.apk`. It uses the permanent release certificate and Android version code 6.
- **macOS:** open `Polydays-0.1.4-macos-arm64.dmg` and copy Polydays to Applications, or use the equivalent `.app.zip`. Requires macOS 12 or newer on Apple Silicon. The bundle remains ad-hoc signed and is not notarized.

The default server is `https://macbook.gibbon-parrotfish.ts.net`. You can select another server on the sign-in screen. Access to the configured private servers requires Tailscale; previously downloaded tasks remain available offline.

`SHA256SUMS` contains asset checksums; `release.json` identifies the shared source commit and default server.
