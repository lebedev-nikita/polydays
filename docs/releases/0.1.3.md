# Polydays 0.1.3

Android and macOS (Apple Silicon) are built from the same source commit.

- Switching between primary destinations and polydays is instant. App bars stay in place instead of sliding across the screen on Android.
- Renamed the unscheduled-task destination from “Бэклог” to “Входящие” throughout the interface.

## Install

- **Android:** install `Polydays-0.1.3-android-arm64.apk`. It uses the permanent release certificate and Android version code 5.
- **macOS:** open `Polydays-0.1.3-macos-arm64.dmg` and copy Polydays to Applications, or use the equivalent `.app.zip`. Requires macOS 12 or newer on Apple Silicon. The bundle remains ad-hoc signed and is not notarized.

The default server is `https://macbook.gibbon-parrotfish.ts.net`. You can select another server on the sign-in screen. Access to the configured private servers requires Tailscale; previously downloaded tasks remain available offline.

`SHA256SUMS` contains asset checksums; `release.json` identifies the shared source commit and default server.
