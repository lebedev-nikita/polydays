# Polydays 0.3.13

Android and macOS (Apple Silicon) are built from the same source commit.

- Expand mobile task text editing to the full screen, with a Back / Edit task / Save header and only the title and description, matching the Todoist reference.
- Preserve the text draft when returning to task details. Keep confirmed property choices saved independently and protect unsaved text when dismissing the task.
- Replace icon-only save and cross controls in existing-task editing with text Save actions and back navigation; keep desktop editing in place.
- Keep the focused fields and Save action above the Android keyboard, including after reopening it. Saving unchanged text still closes the editor without another write.

## Install

- **Android:** install `Polydays-0.3.13-android-arm64.apk`. It uses the permanent release certificate and Android version code 24.
- **macOS:** open `Polydays-0.3.13-macos-arm64.dmg` and copy Polydays to Applications. Requires macOS 12 or newer on Apple Silicon. The bundle is ad-hoc signed and is not notarized.

The default server is `https://polydays.home.arpa`. A saved server address takes precedence. Access requires the configured private network. Downloaded tasks remain available offline.

`SHA256SUMS` contains the APK and DMG checksums.
