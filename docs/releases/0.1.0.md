# Polydays 0.1.0

First development release for Android and macOS (Apple Silicon), built from the shared React Native / React Native for Web application.

- Named daily polydays, including intervals across midnight.
- Backlog, priorities, exact deadlines, recurring tasks and completed history.
- Durable offline editing with server sync and conflict resolution.
- Android home-screen widget with offline task completion.
- macOS application with bundled UI, local task storage and browser-based Google sign-in. The session stays in macOS Keychain.

## Connect

This development release uses `https://macbook.gibbon-parrotfish.ts.net`. Sign-in is restricted to the server owner's Google account. Join the same Tailscale network; the MacBook server must be awake for sign-in and sync. Previously downloaded data works offline.

## Install

- **Android:** install `Polydays-0.1.0-android-arm64.apk` on a 64-bit ARM device. It uses the permanent Polydays release certificate. An earlier debug-signed installation cannot be upgraded in place; sync its pending work before replacing it.
- **macOS:** open `Polydays-0.1.0-macos-arm64.dmg` and copy Polydays to Applications. The `.app.zip` contains the same application. Requires macOS 12 or newer on Apple Silicon.

The macOS bundle is ad-hoc signed, without an Apple Developer ID or notarization. macOS Gatekeeper may prevent opening a downloaded copy under its normal security policy. This is a development distribution, not an App Store release. macOS widgets are planned for a later version.

`SHA256SUMS` contains asset checksums; `release.json` records the source commit and configured server.
