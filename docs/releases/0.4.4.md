# Polydays 0.4.4

Android and macOS (Apple Silicon) are built from the same source commit.

- Reduce the space after each polyday in plans and history across Android, macOS and web.
- Remove stacked polyday/date-group margins while retaining a compact gap between dates and the existing task and button sizes.

## Install

- **Android:** install `Polydays-0.4.4-android-arm64.apk`. It uses the permanent release certificate and Android version code 31. Existing application data is preserved.
- **macOS:** open `Polydays-0.4.4-macos-arm64.dmg` and copy Polydays to Applications. Requires macOS 12 or newer on Apple Silicon. The bundle is ad-hoc signed and is not notarized.

The default server is `https://polydays.home.arpa`. A saved server address takes precedence. Access requires the configured private network and its CA certificate installed on the device. Downloaded tasks remain available offline.

`SHA256SUMS` contains the APK and DMG checksums.
