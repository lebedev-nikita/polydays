# Polydays 0.3.14

Android and macOS (Apple Silicon) are built from the same source commit.

- Restore Android HTTPS connections to the private `home.arpa` server. The private-network migration's trust configuration was missing from later application releases.
- Trust user-installed CA certificates only for `home.arpa` and its subdomains, while requiring HTTPS in release builds. Other servers retain Android's system CA trust.
- Verify the compiled APK's manifest and network policy before staging a release, preventing the configuration from disappearing during packaging.

## Install

- **Android:** install `Polydays-0.3.14-android-arm64.apk`. It uses the permanent release certificate and Android version code 25. Existing application data is preserved.
- **macOS:** open `Polydays-0.3.14-macos-arm64.dmg` and copy Polydays to Applications. Requires macOS 12 or newer on Apple Silicon. The bundle is ad-hoc signed and is not notarized.

The default server is `https://polydays.home.arpa`. A saved server address takes precedence. Access requires the configured private network and its CA certificate installed on the device. Downloaded tasks remain available offline.

`SHA256SUMS` contains the APK and DMG checksums.
