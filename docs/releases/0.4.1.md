# Polydays 0.4.1

Android and macOS (Apple Silicon) are built from the same source commit.

- Fix the Android crash when opening plans or history. Task counts now use Russian plural rules that work in Hermes without `Intl.PluralRules`.
- Preserve grouped dates, shared task summaries and loading more dates while scrolling.

## Install

- **Android:** install `Polydays-0.4.1-android-arm64.apk`. It uses the permanent release certificate and Android version code 28. Existing application data is preserved.
- **macOS:** open `Polydays-0.4.1-macos-arm64.dmg` and copy Polydays to Applications. Requires macOS 12 or newer on Apple Silicon. The bundle is ad-hoc signed and is not notarized.

The default server is `https://polydays.home.arpa`. A saved server address takes precedence. Access requires the configured private network and its CA certificate installed on the device. Downloaded tasks remain available offline.

`SHA256SUMS` contains the APK and DMG checksums.
