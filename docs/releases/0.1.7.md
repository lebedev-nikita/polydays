# Polydays 0.1.7

Android and macOS (Apple Silicon) are built from the same source commit.

- Fixed the web task form moving down when opening the priority menu, including the `!!` shortcut.
- Kept destination menus from moving the form and constrained both menus to the available screen space.

## Install

- **Android:** install `Polydays-0.1.7-android-arm64.apk`. It uses the permanent release certificate and Android version code 9.
- **macOS:** open `Polydays-0.1.7-macos-arm64.dmg` and copy Polydays to Applications. Requires macOS 12 or newer on Apple Silicon. The bundle is ad-hoc signed and is not notarized.

The default server is `https://macbook.gibbon-parrotfish.ts.net`. You can select another server on the sign-in screen. Access to the configured private servers requires Tailscale; previously downloaded tasks remain available offline.

`SHA256SUMS` contains the APK and DMG checksums.
