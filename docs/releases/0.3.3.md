# Polydays 0.3.3

Android and macOS (Apple Silicon) are built from the same source commit.

- Completed the rounded-surface fixes across task entry, task details, date settings and property menus. Borders, backgrounds and shadows follow one contour; pressed rows stay inside rounded groups.
- Added desktop and narrow-screen regression checks for task panel contours and clipping at menu and date-group corners.

## Install

- **Android:** install `Polydays-0.3.3-android-arm64.apk`. It uses the permanent release certificate and Android version code 14.
- **macOS:** open `Polydays-0.3.3-macos-arm64.dmg` and copy Polydays to Applications. Requires macOS 12 or newer on Apple Silicon. The bundle is ad-hoc signed and is not notarized.

The default server is `https://polydays.gibbon-parrotfish.ts.net`. A saved server address takes precedence. The configured service is private; each user needs Tailscale access. Downloaded tasks remain available offline.

`SHA256SUMS` contains the APK and DMG checksums.
