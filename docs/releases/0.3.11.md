# Polydays 0.3.11

Android and macOS (Apple Silicon) are built from the same source commit.

- Close the task or series editor with the checkmark even when the title and description are unchanged, including after saving properties or reverting a text draft. Closing an unchanged editor does not write the task or series again.
- Keep Android task and recurrence panels stable when switching between them.

## Install

- **Android:** install `Polydays-0.3.11-android-arm64.apk`. It uses the permanent release certificate and Android version code 22.
- **macOS:** open `Polydays-0.3.11-macos-arm64.dmg` and copy Polydays to Applications. Requires macOS 12 or newer on Apple Silicon. The bundle is ad-hoc signed and is not notarized.

The default server is `https://polydays.home.arpa`. A saved server address takes precedence. Access requires the configured private network. Downloaded tasks remain available offline.

`SHA256SUMS` contains the APK and DMG checksums.
