# Polydays 0.3.10

Android and macOS (Apple Silicon) are built from the same source commit.

- Keep focused inputs above the Android keyboard on sign-in, initial schedule setup, settings and Mac sign-in confirmation.
- Scroll inline task titles, descriptions and recurrence fields with their surrounding task list so the keyboard cannot cover them.
- Keep deadline fields and task capture usable in modal windows, including after closing and reopening the keyboard.

## Install

- **Android:** install `Polydays-0.3.10-android-arm64.apk`. It uses the permanent release certificate and Android version code 21.
- **macOS:** open `Polydays-0.3.10-macos-arm64.dmg` and copy Polydays to Applications. Requires macOS 12 or newer on Apple Silicon. The bundle is ad-hoc signed and is not notarized.

The default server is `https://polydays.home.arpa`. A saved server address takes precedence. Access requires the configured private network. Downloaded tasks remain available offline.

`SHA256SUMS` contains the APK and DMG checksums.
