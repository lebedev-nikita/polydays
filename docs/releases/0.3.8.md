# Polydays 0.3.8

Android and macOS (Apple Silicon) are built from the same source commit.

- Keep the task calendar's week heading on the month of Monday, including weeks spanning two months or years. The week of 26 October–1 November stays in October; November begins with the week of 2 November.
- Keep dates outside that month visually secondary. Browsing weeks preserves the task's selected date.
- Reduce Android and macOS download sizes by removing unused code and resources and optimizing native release builds.

## Install

- **Android:** install `Polydays-0.3.8-android-arm64.apk`. It uses the permanent release certificate and Android version code 19.
- **macOS:** open `Polydays-0.3.8-macos-arm64.dmg` and copy Polydays to Applications. Requires macOS 12 or newer on Apple Silicon. The bundle is ad-hoc signed and is not notarized.

The default server is `https://polydays.gibbon-parrotfish.ts.net`. A saved server address takes precedence. The configured service is private; each user needs Tailscale access. Downloaded tasks remain available offline.

`SHA256SUMS` contains the APK and DMG checksums.
