# Polydays 0.3.6

Android and macOS (Apple Silicon) are built from the same source commit.

- Fixed saved polyday names remaining unchanged in the current polyday, navigation, task scheduling menus, history and Android widget projections. Renaming now updates the shared slot label immediately; interval boundaries still change from the selected date.
- Display names already saved in future schedules by older clients without requiring users to enter them again. Renaming preserves polyday identities, interval boundaries and task assignments.
- Clarified that the effective date applies to interval changes, and removed the delayed-activation confirmation when only names change.
- Added regression coverage for saved names, repeated edits, current views, scheduling menus, widget projections, historical boundaries and server-side task transfers.

## Install

- **Android:** install `Polydays-0.3.6-android-arm64.apk`. It uses the permanent release certificate and Android version code 17.
- **macOS:** open `Polydays-0.3.6-macos-arm64.dmg` and copy Polydays to Applications. Requires macOS 12 or newer on Apple Silicon. The bundle is ad-hoc signed and is not notarized.

The default server is `https://polydays.gibbon-parrotfish.ts.net`. A saved server address takes precedence. The configured service is private; each user needs Tailscale access. Downloaded tasks remain available offline.

`SHA256SUMS` contains the APK and DMG checksums.
