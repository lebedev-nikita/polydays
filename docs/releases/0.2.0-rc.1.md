# Polydays 0.2.0-rc.1

First release candidate for the 0.2.0 minor release, for Android ARM64 and macOS Apple Silicon. Both platforms are built from the same source commit. This candidate remains a draft GitHub prerelease.

## Changes

- Compact task capture with title and description, expandable scheduling, priority and recurrence controls, and repeated entry.
- Inline task creation and editing, contextual row actions, and undo for completion and deletion.
- Calendar date selection, contextual planning in upcoming polydays and week navigation.
- Search across saved tasks and the next 30 days of recurring occurrences, including an option to show completed tasks.
- Task details in an overlay, a collapsible desktop sidebar, mobile layout refinements and keyboard shortcuts.
- Series edits retain the effective future time or polyday when opened from an older occurrence. Escape closes task parameters before closing the detail view, including from the toolbar.

Polyday scheduling, explicit deadlines, independent recurring occurrences, assigned-polyday history and offline sync retain their existing rules.

## Install and connect

- **Android:** install `Polydays-0.2.0-rc.1-android-arm64.apk`. It uses the existing Polydays release identity and Android version code 2 for upgrades from 0.1.0.
- **macOS:** open `Polydays-0.2.0-rc.1-macos-arm64.dmg` and copy Polydays to Applications, or use the equivalent `.app.zip`. Requires macOS 12 or newer on Apple Silicon.

The configured server is `https://macbook.gibbon-parrotfish.ts.net`. Join the same Tailscale network; sign-in remains restricted to the owner's Google account. The MacBook must be awake for sign-in and sync. Previously downloaded data remains available offline.

The macOS app is ad-hoc signed and not notarized. Downloaded copies remain subject to Gatekeeper. macOS widgets, projects, labels and subtasks are outside this candidate.

`SHA256SUMS` lists asset checksums. `release.json` records the source commit, version and configured server.
