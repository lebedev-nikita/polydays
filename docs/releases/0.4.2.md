# Polydays 0.4.2

Android and macOS (Apple Silicon) are built from the same source commit.

- Make Android widget polyday headings compact, with the name and time on one line.
- Remove the date/count block and empty polydays from the all-polydays widget.
- Keep thin separators between tasks, with no bottom divider after the last task in each section.

## Install

- **Android:** install `Polydays-0.4.2-android-arm64.apk`. It uses the permanent release certificate and Android version code 29. Existing application data is preserved.
- **macOS:** open `Polydays-0.4.2-macos-arm64.dmg` and copy Polydays to Applications. Requires macOS 12 or newer on Apple Silicon. The bundle is ad-hoc signed and is not notarized.

The default server is `https://polydays.home.arpa`. A saved server address takes precedence. Access requires the configured private network and its CA certificate installed on the device. Downloaded tasks remain available offline.

`SHA256SUMS` contains the APK and DMG checksums.
