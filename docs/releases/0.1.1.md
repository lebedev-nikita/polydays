# Polydays 0.1.1

Android and macOS (Apple Silicon) receive the same task editor improvements.

- Compact task capture with borderless title and description, a horizontal property toolbar and one submit action.
- Separate date panel with calendar, quick dates and optional deadline time; short menus for priority and polyday destination.
- Type `!!` or `#` at the end of a title to choose priority or destination.
- Cancel date and recurrence changes without losing the task draft. Unsaved edits are protected when closing or switching between an occurrence and its series.
- Improved field validation, keyboard focus and narrow-screen layouts. Offline capture and independent occurrence edits remain supported.
- Schedule settings use compact interval rows, quick time entry, searchable timezones and a calendar for their effective date.

## Install

- **Android:** install `Polydays-0.1.1-android-arm64.apk`. It uses the permanent release certificate and Android version code 3.
- **macOS:** open `Polydays-0.1.1-macos-arm64.dmg` and copy Polydays to Applications, or use the equivalent `.app.zip`. Requires macOS 12 or newer on Apple Silicon. The bundle remains ad-hoc signed and is not notarized.

This development distribution connects to `https://macbook.gibbon-parrotfish.ts.net`; sign-in is restricted to the server owner on the same Tailscale network. Previously downloaded tasks remain available offline.

`SHA256SUMS` contains asset checksums; `release.json` identifies the shared source commit and server.
